# zApkStart

[English](README.md) | עברית

**zApkStart הוא fork של [ApkStart](https://github.com/RoutineMiku/apkstart) מאת RoutineMiku** —
יישום Windows שמריץ יישומי אנדרואיד כמו תוכנת מחשב רגילה: לחיצה כפולה על קובץ ‎`.apk` מתקינה אותו,
וכל יישום מקבל חלון משלו, זהות בשורת המשימות ורשומה בתפריט התחל — על גבי סביבת אנדרואיד
מנוהלת־עצמאית (QEMU + תמונת מערכת Google Play) בלי אמולטור נוסף ובלי מתאמי רשת וירטואליים.

ל‑fork שלוש הוספות שאין במקור:

1. **אנגלית ועברית, במלואן.** הממשק של המקור הוא בסינית. zApkStart מתרגם את כל מה שהמשתמש רואה —
   אשף ההתקנה, מסך הפתיחה, החלון הראשי, מגש המערכת, התראות, הגדרות, המדריך, וכל הודעות השגיאה
   והאבחון — לאנגלית ולעברית, כולל פריסת ‏RTL מלאה בעברית. שפת המערכת של אנדרואיד האורחת עוקבת
   אחרי שפת הממשק שנבחרה (אורח עברי עולה עם ‏`he-IL`); ה‑IME הסיני המובנה מותקן רק כשנבחרה סינית.
2. **תמיכה ישרה ב‑Windows 11 ARM64.** היישום מופץ בגרסאות ARM64 מקוריות. את מנוע האנדרואיד אי אפשר
   להריץ באופן מקורי כיום — Google מפרסמת בינאריים של האמולטור ל‑Windows רק ל‑x64 — ולכן ב‑ARM64
   היישום אומר בדיוק מה עובד ומה לא (טבלה למטה), וכל ניסיון להריץ את מנוע ה‑x64 דרך האמולציה של
   Windows הוא בחירה מפורשת, לא ברירת מחדל.
3. **זהות ועדכונים עצמאיים.** zApkStart מותקן ומתעדכן כמוצר נפרד מ[ההפצות שלו](https://github.com/zeevrussak/zApkStart/releases)
   ולעולם לא יוריד גרסה מהפרויקט המקורי. הקרדיט למקור מופיע ב‑[NOTICE.md](NOTICE.md) ובתוך היישום.

## מטריצת יכולות לפי מעבד

| מארח | המעטפת (היישום) | מנוע האנדרואיד | הערות |
| --- | --- | --- | --- |
| Windows 10/11 x64 | מקורי | מקורי (אמולטור/QEMU של Google ל‑x64, עם האצת AEHD או WHPX) | החוויה המלאה, כמו במקור |
| Windows 11 ARM64 | מקורי (בניית ARM64) | **אינו זמין באופן מקורי.** Google אינה מפרסמת אמולטור ל‑ARM64; מנוע ה‑x64 תחת אמולציית Windows עובר שני תרגומי תוכנה ואינו שמיש ליישומים אמיתיים | היישום מדווח על כך בהרצה הראשונה; בחירה מפורשת מאפשרת לנסות את מנוע ה‑x64 בכל זאת (ניסיון אחד, עם הסבר ציפיות) |

מנוע אנדרואיד מקורי ל‑ARM64 מתועד — בלי להישלח במוצר — ב‑[docs/zapkstart/arm64-research.md](docs/zapkstart/arm64-research.md).

## הורדות

בנייה מקוד המקור (למטה) או הורדה מ[ה‑Releases](https://github.com/zeevrussak/zApkStart/releases).
קובצי ההפצה נושאים את הקידומת `zApkStart-`: קובצי zip ניידים (x64 מלא/קל, ARM64 קל), מתקיני NSIS,
וחבילת ‎`zApkStart-runtime-*.zip` שההפעלה הראשונה מורידה אוטומטית לגרסאות בלי רנטיים מובנה.

zApkStart **אינו** יישום ה‑Microsoft Store ‏"ApkStart" ואינו משתמש ברישום שלו.

## תאימות מול ApkStart המקורי

שני המוצרים יכולים להיות מותקנים זה לצד זה אבל אינם חולקים דבר: תיקיות נתונים שונות
(‎`%APPDATA%\zapkstart` מול ‎`%APPDATA%\apkstart` של המקור), תיקיות שיתוף שונות, מכשירי אנדרואיד
וירטואליים שונים. אין הגירה מהתקנה של המקור. ראו [NOTICE.md](NOTICE.md).

## בנייה מקוד המקור

```powershell
npm install          # תלות (רנטיים של Electron יורד כאן)
npm test             # בדיקות יחידה ומנוע, Node טהור
npm start            # הרצה ראשונה: הקמת הרנטיים (adb / emulator / תמונת Play)
npm run pack         # בנייה ניידת (x64)
npx electron-builder --win nsis --arm64 --config electron-builder.yml   # בניית ARM64 צולבת
```

ה‑CI בונה צולב את מתקין ה‑NSIS ל‑ARM64 ומאמת שהבינארי שהתקבל הוא ‏PE‏‏ ‏ARM64 אמיתי
(‎`scripts/check-pe-arch.js`).
